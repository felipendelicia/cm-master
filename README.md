# CM Master

Proyecto de skill de Community Manager para Codex y Claude Code, inspirado en el perfil de marca editable de Google Pomelli.

**Estado: diseño en revisión. La skill todavía no está implementada ni disponible para instalar.**

El alcance propuesto incluye varias marcas, manual de identidad desde la web y conversación, contenido final, calendario editorial, aprobación humana antes de publicar, análisis de resultados y competidores. Incluye publicación en LinkedIn, Instagram, Facebook y X mediante control de un navegador autenticado, sujeta a las capacidades y controles del host, la cuenta y el servicio, con verificación del resultado.

Leé el [diseño de la primera versión](docs/superpowers/specs/2026-10-27-cm-master-design.md) para ver el flujo completo, las decisiones confirmadas, las propuestas y los límites de herramientas y suscripciones.

Los datos operativos de las marcas se conservarán en carpetas locales fuera de este repositorio público.
